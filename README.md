## 🚀 Featured Projects

### ⚡ DareXAI — AI Business Operations Platform
> *Built in 48 hours as a Full Stack AI Engineer internship assignment*

A **production-grade multi-tenant SaaS** where business owners operate by talking to an AI agent.

| Feature | Details |
|---|---|
| 🤖 **AI Agent** | Gemini 2.0 Flash with 5 native tool calls — searchContacts, createTask, updateOpportunity, sendWhatsApp, fetchMetrics |
| 🌊 **Streaming** | SSE token-by-token streaming on Edge Runtime — no Vercel 10s timeout |
| 🔐 **Auth** | Google OAuth PKCE + JWT (15min) + Refresh Token Rotation (SHA256 hashed, single-use) |
| 🏢 **Multi-Tenant** | `tenantId` enforced at query level via `withTenant()` Prisma wrapper — structural isolation |
| 📱 **WhatsApp** | Real Meta Cloud API + mock fallback (env-var toggle, zero code change) |
| 📋 **Audit Trail** | Every AI tool call writes AuditLog row — actor, action, metadata, timestamp |
| 🔄 **Workflow** | Lead → AI Score → WhatsApp → Task → Audit (full automation pipeline) |
| 📊 **Unified Inbox** | WhatsApp + Email + Call logs in one timeline with AI summary + sentiment |

**Stack:** `Next.js 14` `TypeScript` `Prisma` `PostgreSQL` `Gemini API` `Zod` `jose` `bcryptjs` `Zustand` `React Query` `shadcn/ui` `Vitest` `Vercel`
